# Maui.MobileAds iOS
iOS Bindings for Google's Mobile Ads SDK to use in .NET MAUI.

Forked from [Redth/Maui.GoogleMobileAds.iOS](https://github.com/Redth/Maui.GoogleMobileAds.iOS).

## Building

```pwsh
pwsh ./build.ps1 -MobileAdsVersion '13.10.0' -UserMessagingPlatformVersion '3.1.0' -BuildNuGet $true -GenerateBindings $false -IsRelease $true
```
